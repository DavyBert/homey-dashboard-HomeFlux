Background

First choose how HomeFlux determines day and night. Realistic / automatic combines that choice with the weather source; manual can override the period and weather scene.
Scene set
Choose the illustration family used for the background images.
Day/night control
Top-level day/night control. Realistic / automatic always uses this setting; manual uses it when Period is set to Automatic.
Day from
Local time according to Homey's timezone.
Night from
Local time according to Homey's timezone.
Mode
Realistic / automatic combineert de bovenstaande dag/nachtregeling met de gekoppelde weerbron. Manual laat je periode en weerbeeld zelf kiezen.
Weather device / capability
Choose a weather/condition/rain capability from an installed weather device, for example KMI. Homey's built-in weather condition is not exposed as a regular device capability and may therefore not appear in this list.
Period
Only used in manual mode. Automatic follows the top-level day/night control; Day or Night temporarily overrides it.
Weather scene
Only used in manual mode or as fallback when the weather value is not recognized.
Panel transparency
0% = fully visible, 100% = fully transparent. Applies to the panels on the illustration and the extra cards.
Standby line blink tempo
Shared calm blink tempo for PV, battery and grid when blinking is enabled per line.
Overlay colour
Automatic follows day/evening. Light or Dark forces the colour of the information panels.
Refresh interval
Widget fallback for quiet sources. Outside an open widget, HomeFlux does not periodically poll sources.
Widget text size
Fixed text size for the energy cards, independent of the system font size.
Title text size
Adjust only the names at the top of the energy cards, such as Solar and Battery.
